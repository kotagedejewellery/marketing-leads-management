# Design

<!-- impeccable:design-schema 1 -->

## Visual Direction

KGJ Atelier Console: an operational workspace for a premium jewellery team, with a warm mineral canvas, a graphite command bar, bronze as a meaning-bearing action colour, and quiet data-first surfaces. The interface should feel like a well-maintained consultation book with a modern control room's clarity, never a generic SaaS dashboard.

## Mode

Operate

## Direction Contract

- First viewport: a graphite command surface frames the work, then the page moves quickly into a scannable lead ledger or operational funnel.
- Signature interaction: consequential actions use the same focused confirmation dialog; success and errors resolve through visible, concise feedback.
- Typography: a tuned system sans with decisive headings and uppercase micro-labels for metadata; data uses tabular numerals.
- Rhythm: broad page margin, 12–16px component radii, dense but breathable table rows, and one elevation vocabulary for paper surfaces.
- Accessibility: status never relies on colour alone; every control retains a visible label, keyboard focus, and at least a 44px target for primary actions.
